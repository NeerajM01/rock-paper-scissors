# 🪨📄✂️ Rock Paper Scissors Deluxe

A modern, interactive, high-stakes version of the classic Rock Paper Scissors game built with **Streamlit** and Python. Features custom audio effects, visual animations, real-time score tracking, and a dynamic betting mechanism!

---

## ✨ Features

- 💰 **Dynamic Betting System**: Start by placing your bet (in ₹ Rupee). Win rounds to double your balance or lose to cut it in half!
- 🎵 **Audio & Visual Effects**: Real-time sound effects (cheers, clangs, pops) paired with Streamlit animations (balloons and custom CSS keyframes).
- 📊 **Live Scoreboard & Progress**: Track your overall score against the AI and monitor your bankroll via an interactive progress bar.
- ⚡ **Interactive UI**: Clean, responsive, multi-column button layout powered by Streamlit state management.

---

## 🎮 Game Rules & Mechanics

1. **Set Your Bet**: Input an initial starting amount to begin the game.
2. **Make Your Move**: Choose between **🪨 Rock**, **📄 Paper**, or **✂️ Scissors**.
3. **Outcome**:
   - 🏆 **Win**: Double your current balance! (`Balance × 2`)
   - 💀 **Loss**: Lose half your current balance! (`Balance ÷ 2`)
   - 🤝 **Tie**: Balance remains unchanged.

## 🚀 Quick Start & Installation

### 1. Prerequisites

Ensure you have Python 3.8 or higher installed on your system.

### 2. Clone the Repository

```bash
git clone https://github.com/NeerajM01/rock-paper-scissors.git
cd rock-paper-scissors-deluxe
```

### 3. Install Dependencies

Install Streamlit using `pip`:

```bash
pip install streamlit
```

### 4. Run the Application

Launch the Streamlit app locally:

```bash
streamlit run app.py
```
